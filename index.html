The fine print

About this simulation

All patients and facilities here are fictional. This is a learning activity for the Regional LHS ML Info 1 Summit talk; it is not a clinical system, an official DOH product, a privacy compliance test, or an LHS maturity assessment.

Choices illustrate general information management principles. In actual work, follow current clinical guidance, law, local authorization, and approved procedures. The four indicators in this game explain consequences; they are not validated scores.

Privacy

No account, analytics, advertisement, external font, or remote game API. You can optionally save mode and completed cases on this device. No patient data is accepted. GitHub Pages, if used for hosting, has its own infrastructure logs.
